# S/ Material Generation Standard

This repository implements the Case-Lab-Viva architecture coordinated in the S/ Agent University Linear project.

## Invariant

No material release is certifiable unless it is:

- tied to an eligible Passport and owner
- grounded in approved source claims
- designed backwards from observable capability
- mapped from outcome to practice and assessment
- tested with an unseen transfer variant and repeated trials
- checked for identity, authority, safety, provenance, and owner control
- independently reviewed by Faculty QA
- versioned with a reproducible evidence manifest

Passing assessment never activates an agent automatically. It creates an owner-reviewable Passport handoff only.

## Release bundle

A complete release contains nine versioned artifacts:

1. source registry
2. scholar note
3. decision case
4. lab simulation
5. assessment rubric
6. remediation pack
7. thesis/viva
8. faculty QA
9. evidence manifest

NotebookLM and similar tools are source workspaces. The approved claim registry and evidence package are the auditable system of record.
